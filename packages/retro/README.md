# Retro & Classic Games Catalog 🎮

Classic Android 4.4 KitKat games (such as Hill Climb Racing Mod, Minecraft PE, Subway Surfers, Angry Birds Classic, Angry Birds Go!, Flappy Bird, and QuickPic) are dynamically downloaded and installed on-demand via:

```bash
my-tablet-server retro
# or: bin/retro-store
```

All games are hosted on verified Archive.org mirrors. If you wish to install them offline, place your corresponding `.apk` files directly in this directory before running `./install.sh`.
