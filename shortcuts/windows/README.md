# 🪟 Windows Batch Shortcuts

Double-click any `.bat` file in this directory to control your tablet from Windows:

- Actions run invisibly in the background using PowerShell hidden execution (`-WindowStyle Hidden`), avoiding lingering console windows.
- Interactive shortcuts (`20-tablet-menu.bat`, `21-tablet-terminal.bat`) open a dedicated Command Prompt/PowerShell window to let you interact directly with the menu or tablet Linux terminal.
