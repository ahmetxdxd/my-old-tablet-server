# 🐧 Linux & macOS Desktop Shortcuts

Double-click any `.sh` script in this directory to control your tablet silently in the background:

- **`.sh` files**: Direct shell launchers that invoke `.run_silent.sh` with desktop notifications (`notify-send`).
- Interactive tools (`20-tablet-menu.sh`, `21-tablet-terminal.sh`, `06-cava-audio-visualizer.sh`, `22-auto-downloader.sh`) automatically open your preferred terminal emulator (`konsole`, `x-terminal-emulator`, `gnome-terminal`, etc.).
