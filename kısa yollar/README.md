# ⚡ My Tablet Server - Çift Tıklanabilir Hızlı Kısayollar

Bu klasör, tablet sunucunuzun tüm temel özelliklerini **terminal penceresi görmeden, tek bir çift tıklama ile** kullanabilmeniz için hazırlanmıştır.

---

## 🖥️ Nasıl Kullanılır?

### 🐧 Linux & macOS Kullanıcıları:
- Dosya yöneticinizde (Dolphin, Nautilus vb.) dilediğiniz **`.desktop`** veya **`.sh`** dosyasına **çift tıklayın**.
- Sistem, **hiçbir terminal penceresi açmadan** işlemi arka planda başlatır ve sağ alt köşede masaüstü bildirimi (`notify-send`) gösterir.
- Dilerseniz bu kısayolları masaüstünüze (`~/Desktop`) kopyalayarak masaüstü simgesi olarak da kullanabilirsiniz.

### 🪟 Windows Kullanıcıları:
- Dilediğiniz **`.bat`** dosyasına **çift tıklayın**.
- Arka planda penceresiz (gizli) olarak çalışır ve fonksiyonu anında devreye sokar.
